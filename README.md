<h1>WeLoveMovies</h1>
<p>This project is designed to test your ability to build complex servers and access data through a database.</p>
<img src="![image](https://github.com/user-attachments/assets/ec261bfa-09bd-4146-aa27-24cb6f633638)">
<p>To succeed at this project, you'll need to demonstrate that you can do the following tasks:</p>
<p>
 <ul>
  <li>Install and use common middleware packages</li>
  <li>Receive requests through routes</li>
  <li>Run tests from the command line</li>
  <li>Access relevant information through route and query parameters</li>
  <li>Create an error handler for the case where a route doesn't exist</li>
  <li>Build an API following RESTful design principles</li>
  <li>Create and customize a <code>knexfile.js</code> file</li>
  <li>Create a connection to your database with Knex</li>
  <li>Write database queries to complete CRUD routes in an Express server</li>
  <li>Return joined and nested data with Knex</li>
  <li>Write database migrations using Knex's migration tool</li>
  <li>Deploy your backend server to a cloud service</li>
 </ul>
</p>
<p>You will not need to make any edits to HTML or CSS for this project.</p>
<h2>General Tasks</h2>
<p>You will also need to make sure that the following tasks are complete:</p>
<p>
 <ul>
  <li>Your <code>app.js</code> file and <code>server.js</code> file are correctly configured, with your <code>app.js</code> file exporting the application created from Express.</li>
  <li>You use the <code>cors</code> package so that requests from the frontend can correctly reach the backend.</li>
  <li>If a request is made to a route that doesn't exist, the server returns a <code>404</code> error.</li>
  <li>If a request is made to a route that exists but the HTTP method is wrong, the server returns a <code>405</code> error.</li>
  <li>All of your routes respond with the appropriate status code and use a data key in the response.</li>
